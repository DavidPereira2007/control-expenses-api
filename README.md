# Control Expenses API

A simple expense control API built with ASP.NET Core and PostgreSQL for study and didactic purposes.

---

# About

This project was created to practice:

- REST API development
- CRUD operations
- ASP.NET Core
- Entity Framework Core
- PostgreSQL integration
- Database persistence
- API architecture concepts

The API allows basic expense management operations such as:

- Creating expenses
- Listing expenses
- Updating expenses
- Deleting expenses

---

# Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Swagger/OpenAPI
